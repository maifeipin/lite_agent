# Antigravity：VPS2 隔离预发布与逐项验收指令

你负责 VPS2 部署验收，Codex负责本地阶段三收口和验收复核。首先读取 .agents/AGENTS.md、stage-3-final-closeout-20261017.md、release-runbook.md、stage-2-migration-inventory.md、kernel-acceptance-matrix.md、stage-3-compatibility-consumer-inventory.md。历史风险 HISTORY_UNRESOLVED 已被用户接受用于本地验收，不得改称已定位或已修复。

## 入口与责任

使用包含本文件及阶段三收口说明的本地提交，开始前记录完整 Agent SHA、Parser SHA、工作区状态、Python和依赖版本；不得默认使用远端旧HEAD，不得擅自push以传输代码。优先传输该提交的源码归档，核对哈希；不复制整个本机工作区。若无法唯一确定该提交，停止部署并说明实际阻碍。

用户授权你参与VPS2部署测试，不包含VPS1写入、生产重启或生产数据变更。先从已有授权配置核实VPS2身份及访问方法；无法确认时向用户索取目标信息，不猜地址、账号、凭据。先只读预检并记录目标主机身份、现有进程/端口/服务、磁盘、Python、Parser依赖及冲突；不得覆盖原服务。需要sudo或安装系统包时遵守实际授权边界。不得输出密钥或把生产数据库下载至本机。

## 先完成隔离，再启动

使用独立部署目录、venv、服务名、端口、日志和数据目录。配置文件权限收紧；排除配置和运行数据的源码传输清单留档。不要新建复杂基础设施或改写工具实现。

复用LLM服务与模型，优先独立测试凭据、预算和并发上限；共用凭据时明确配额影响并限制测试量。仅启用另一个微信账号，session_file、contexts_file、cursor_file使用独立绝对路径，禁止复制VPS1登录态。其余频道显式关闭，管理员仅测试账号。

逐项审计配置合并优先级、conf.d、环境变量、通知端口和业务直连目标，不能只关闭频道就宣称零生产副作用。数据库、搜索索引、博客、邮件收件人、云备份目的地使用测试目标；不可隔离的能力暂不启用。严禁生产自动发信、生产账单状态修改、生产数据恢复及VPS1网络切换。

当前插件可用CLI --plugins、LITE_AGENT_PLUGINS或配置enabled白名单；按源码确认优先级。插件加载可能同时注册cron与后台worker；网络failover还有默认开启行为。每个插件启用前列清工具/命令/路由/cron/worker/输出目标，确保不会启动未批准的任务。不存在的dry-run开关不得臆造；需要实现新安全开关时单独提交最小设计交Codex复核，不绕过隔离要求。

## 分批执行

1. core + LLM + 微信：真实收发、连续上下文、/new、授权/未授权、异常超时、重复消息、重启恢复和优雅退出。确认没有业务作业。
2. 每次一个插件，先只读查询；再在独立测试数据上验证写入。建议内容查询、Todo、会议、邮件、账单、系统与网络操作按实际风险排序。插件内仍有写工具时，仅口头要求模型不调用不构成隔离。
3. 定时与后台作业最后逐个启用，先检查收件人和存储目标。验证实际执行、去重、停止与重启，观察窗口至少覆盖要验收任务的实际调度周期。未到周期的项目如实标待验证，手动触发不得冒充自然调度。
4. 网络切换、恢复、云同步等高影响动作先做可回滚演练方案；没有隔离目标或明确授权时不执行真实动作，记录缺口。

逐项使用验收表：能力ID、旧入口/规范实现、启用配置、数据与输出目标、输入、预期输出及状态、副作用、实际结果、脱敏证据、回滚验证。覆盖正常、权限拒绝、依赖不可达、超时和重启路径。未测不能填通过；不要用单元测试数量代替真实链路验收。

## 失败与交付

失败立即保留完整stdout/stderr、退出码、时间、版本和脱敏配置摘要，禁止无限重跑掩盖失败。业务行为偏差先报告Codex；禁止自行重写原算法、删除兼容入口、放宽门禁。不得为测试中断VPS1生产服务。

交付：精确版本与归档哈希、目标环境清单、配置键差异（无凭据）、逐项验收表、实际作业观测时间、失败与修补记录、未验证项、日志索引、VPS2停止/回退命令及VPS1候选发布范围。只有微信通过不能宣称其它频道通过。

到此停止，交Codex复核。不得向VPS1发布、push、替换生产配置/数据库/微信状态。后续正式发布只迁移同一验证版本的代码与依赖，生产状态单独保护。
